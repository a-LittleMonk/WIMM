02 Animal

Information about the animal in this video. It is optional for the analysis but written into every export, so you can sort and group the results in Excel or your statistics program.

FieldUse
Animal IDThe animal's code (e.g. M01). Shown on the Queue row and used as the sheet / row name in combined exports.
GroupTreatment or genotype (e.g. Saline / KO).
SexMale / Female.
Trial #Trial or day number.
DateYYYY-MM-DD.
NotesFree text.
Animal information always stays with its own video — Run all and Copy arena and zones… never copy it to other videos unless you tick Animal information there, and even then each video keeps its own Animal ID (Copy arena and zones).
For blinded scoring, put only the animal code in Animal ID and keep the group key elsewhere; add the group column in Excel after the analysis.
