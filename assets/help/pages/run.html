Run one video, Run all, Stop

One video

Click ▶ on the video's Queue row. It runs with the settings shown in the panel for that video. When it finishes, the row says Completed and the status line "Done: name".

All videos (batch)

  1. Set everything up on one video and click that video so it is shown in the panel — it is the settings video.
  2. Make sure every video has its own arena (and its own zones, scale line, crop and animal information where needed). Rows without an arena say Needs setup.
  3. Click Run all. A pre-flight check lists what is shared:

  1. Videos are tracked one after another. The Run panel shows the batch progress, elapsed time and estimated time left; the header pill shows the current video.

What is shared and what stays per video: Batch rules.

Stop

Stop ends the run. The video being tracked when you press it is not saved — it goes back to Ready and keeps its earlier results, if any. Videos finished before it keep their results. Re-run the stopped video later.

Closing the window during a run asks first; answering Yes stops tracking and closes (the unfinished video is not saved).

One run at a time

Only one video can be tracked at a time, in all experiments together. Starting another run while one is going shows "Run in progress" — wait, or press Stop.

After each video

  • The results appear in the Output tab and the video's row says Completed.
  • A backup Excel file of the video is saved automatically to the backup folder (Files and folders).
  • When the run ends, one message lists anything that needs your attention: failed videos, videos that ended early, low detection. → Messages after a run
The window answers more slowly while a video is tracked and pauses briefly while the results and backup are written. This is normal.
