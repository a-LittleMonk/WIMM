The Output tab

Shows the results of the video shown in the panel. Click another video in the Queue to see its results. The green Tracked badge means this video has results.

Summary

Every measure, grouped (Recording, Locomotion, the zones of the test …). Use the Distance, Speed and Time boxes to show the values in other units (cm / mm / m, cm/s … km/h, s / min); the Excel files contain every unit anyway. Copy table copies the table for pasting into Excel or a document. The measures are explained on each experiment's page and in Locomotion / Zone measures.

Top right: Move threshold and Time bin show the analysis settings; Edit changes them here — results are recomputed instantly, without tracking again.

Raw data

One row per frame: frame number, time (s), X / Y position (px), step distance, speed, the zone the mouse is in, and the nose / tail positions. Corrected and interpolated frames are counted in the Summary (Corrected Frames (%)). Column details: Inside the Excel files.

Graphs

Trajectory, heatmap, speed over time, speed histogram, zone time, and the test's own graphs. → Graphs

Cell info (Open Field)

The 16 cells of the 4×4 grid, each labelled Corner, Side or Middle (click a cell to relabel it; Apply standard 4×4 restores the default; Clear all → Custom starts empty). Aggregated by region sums time, entries and % time per label. Per-cell values need Grid 4×4 in Zones.

Video config

Every setting this video was analysed with, and the app version — the same list as the Video Config sheet of the Excel file. Use it for the methods section.

Export to Excel

Saves this video's results (Summary, Raw Data, Time Bins, Video Config, Graphs) plus CSV copies to a folder you choose. Batches: see Exporting.
