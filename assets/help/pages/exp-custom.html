Custom Experiment — design your own test

Draw your own zones and lines on any apparatus, choose what to measure, and save the design under a name. It then appears in the start page list like a built-in test.

Create a design, step by step

  1. Start page → New experiment → Create.
  2. Add a video; Arena (03): click the 4 corners of the apparatus.
  3. Add zones: circle, rectangle, polygon, or a line. Drag on the preview to draw it (polygon: click the corners, Enter to finish, Backspace removes the last corner, Esc cancels). Name each zone and pick whether the body or the nose counts.
  4. Tick the measures:
    MeasureGives
    Time / % of session / Entries / LatencyFor each zone (on by default).
    Mean visitAverage visit length per zone.
    Distance / SpeedDistance moved and mean speed while inside each zone.
    SequenceOrder of the zones entered and the number of zone changes.
    Line crossingsHow often each line was crossed and when first.
    LocomotionDistance, speeds, mobility and pauses of the session.
  5. Save and type a name. The design is stored as a file (any language for the name; two names never overwrite each other — saving an existing name asks first).

Use, edit, delete

  • Start page → pick it in Open an experiment → Open. The design is fixed; each video needs only its arena (and scale).
  • Edit design changes zones or measures; Delete removes it.
  • A saved design file that can't be read is not listed; the app tells you which file.

Zones are placed relative to the arena, so the same design fits every video once its 4 corners are set.
