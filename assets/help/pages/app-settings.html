Menus and app settings

Top bar buttons

ButtonDoes
Corrections Ctrl+KManual corrections (inside a test).
Graphs Ctrl+GGraph style editor (inside a test).
AppearanceColours of the app (below).
Logs Ctrl+LThe app's event log of this session (errors, warnings, every run). Save to file for support.
Simple / FullSimple hides advanced controls.

Settings menu

ItemDoes
Set Output Folder…Default folder offered by the exports.
Set Backup Folder…Where the automatic backup after every run goes (default: the backup folder next to the app). If the chosen folder can't be reached (USB unplugged, network down), backups go to the default folder and you are told.
Refresh app F5Reloads the interface.

Appearance

Separate palettes for light and dark mode: preset, background, gradient colours, panels and their opacity, highlight colour. Reset colours returns to the defaults. The sun / moon in the header switches light / dark.

Logs

Warnings and errors are also kept in settings/wimm.log after the app closes (Files and folders).
