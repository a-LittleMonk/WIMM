Novel Object Recognition

Recognition memory: a mouse that remembers the familiar object explores the novel one more. Exploration = the nose inside an object's interaction zone.

Set-up, step by step

  1. Arena (03): premade square or 4 corners.
  2. Zones (04), for Object A and Object B:
    • Name (shown on the video and in Excel), Role Familiar / Novel (needed for the discrimination index).
    • Place, then click the object's centre on the preview.
    • Shape (circle, square, triangle, custom with Corners) and Size in cm (diameter / side).
    • Pad: how far around the object counts (cm; 2 cm is common).

  3. Optional: Require nose facing object with a Max angle (45° default): frames count only when the head points at the object — rejects passing by.
  4. Scale (05) is needed so sizes in cm are right. Nose detection is on by default.
  5. Check that the nose marker is at the snout, then run.
