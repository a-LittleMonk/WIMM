Each export asks for the folder (it opens in the last folder used). Graph style chooses the graph preset used in exported files.

Before a batch export

The app makes sure each video's numbers and graphs match its current settings. If you changed settings after running, those videos are recomputed first. If a video's numbers can't be brought up to date, the export stops and names the video — it never exports out-of-date numbers. Videos that can't be opened are skipped and listed.

Annotated video

  1. Tick the overlays: arena outline, center zone, grid, exclusion mask, bounding ellipse, trail, trail fade, marker info tag, cell highlight / numbers / timer / entries, and Apply preprocessing (shows the detection picture).
  2. Choose Body markers, Trail length and Smooth path.
  3. Render: Current video, All completed or Pick…, then Render…. Stop cancels.

The video covers the trimmed part. It is useful for presentations and for showing reviewers how the tracking looks.

File names

  • Combined: <experiment>_combined-<date-time>.xlsx; raw data: <experiment>_raw-<date-time>.xlsx.
  • Backup: <video name>_<experiment>.xlsx. Two queued videos with the same file name from different folders get the folder name in front (Day1_m1_open_field.xlsx, Day2_m1_open_field.xlsx).
A file that is open in Excel can't be overwritten. The message "… can't be written — it is probably open in Excel" means: close it and export again.
