Troubleshooting — every message explained

Messages

MessageCauseWhat to do
Can't open file — the file is missing, empty or damaged.The video can't be read.Check the file plays in a video player; re-export it from the camera software; remove it from the Queue.
Can't read this video's frame rate. Set an FPS override…The file reports an impossible rate and has no time stamps.Enter the camera's real rate in Video → FPS override.
The arena has almost no area… Redraw it.The 4 corners are on one spot or one line.Redraw the arena.
Perspective correction is on, but it can't be built…Corners missing or invalid.Redraw them or turn perspective correction off.
The calibration line has no real length…Real length 0 cm.Enter the length in Scale.
Automatic scale (px/cm) failed…The automatic scale couldn't be computed (e.g. maze points missing).Fix the maze outline, or draw a calibration line.
Arena not definedThe video has no arena.Click its row and draw the arena.
Run in progressAnother video is being tracked.Wait, or press Stop.
Stopped by user — partial run not savedYou pressed Stop.Run that video again.
Low detection rateMouse found in < 90 % of frames.Detection guide.
These videos stopped decoding earlyThe file ends or breaks before its stated length.Check / re-export the file.
… can't be written — it is probably open in Excel…The target file is open in another program.Close it and export again.
The backup of video could not be saved…The backup file is open or the folder is not writable. The run itself succeeded.Close the file; export the video's results before closing the app.
The backup folder … can't be reachedChosen backup folder missing (USB, network).Backups went to the default folder; reconnect or choose another folder.
Export stopped — numbers could not be updated…A video's results couldn't be recomputed with its current settings.Open that video, check its settings and View → Logs, run it again.
Some videos skipped — could not be openedVideo moved or renamed after tracking.Put the file back or re-add it.
file.json was damaged and could not be read…A settings file was corrupted.Defaults are used; the damaged file is kept as .bad-<date>.
The saved experiment … could not be readA custom design file is damaged.Recreate the design.
The graph '…' could not be drawnA graph failed; it is missing from the export.See View → Logs; the numbers are not affected.
Unexpected errorA programming error.The app keeps running. Send settings/wimm.log with a description.
