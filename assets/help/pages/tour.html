The main screen

1 — Header

  • Mice Tracker logo: back to the start page (also Ctrl+H). Next to it, the name of the current output folder.
  • View menu: Logs, Tracking corrections, Customize graphs, Appearance, Simple mode. Settings menu: Extra features, Refresh app, Set Output Folder, Set Backup Folder. → Menus and app settings
  • Simple / Full: Simple hides the advanced controls; Full shows everything.
  • Sun / moon: light or dark theme.
  • Logs: the app's event log. Help: this window (F1).
  • While a video is tracked, a small pill shows its name and progress.

2 — Queue

The videos of this experiment. The counters show how many are Done, Running, Ready and need Attention (no arena, or a failed run). Each row shows the video's status; its buttons are ✂ (trim / crop), ▶ (run only this video) and ✕ (remove from the list). Click a row to show that video in the panel.

StatusMeaning
Needs setupNo arena yet — draw it before running.
ReadyCan be run.
Tracking nn%Running now.
CompletedResults are ready (and backed up).
ErrorThe last run failed; the reason is shown at the bottom of the Queue and in the end-of-run message.

3 — Configuration

Eight cards, top to bottom in the order you use them. Click a card's header to open or close it. The dot on the right shows its state: green = done, amber = optional or not set, red = must be fixed. Apply to… copies settings to other videos (Apply to).

4 — Preview, Output and Export

  • Preview: the video with the arena, zones and the detected mouse drawn on it; player controls and the timeline below. → Preview and player
  • Output: the results of the shown video. → Output tab
  • Export: Combined Excel, raw data, vector graphs and annotated video. → Exporting

5 — Run panel

Run all runs every video in the queue; Stop stops the run (the video being tracked is not saved). Below: batch progress, elapsed time and the estimated time left. → Running

The window can be made as small as 1000 × 600; at smaller sizes nothing would fit. Drag the borders between the three panels to resize them.
