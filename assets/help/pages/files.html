Files, folders and reproducibility

Everything the app stores lives in the app's own folder — nothing in your user profile or AppData. Deleting the folder removes it all; each copy of the app has its own settings.

Location (inside the app folder)Contents
settings/mice_tracker.jsonApp settings (theme, folders, graph styles …).
settings/detection_presets.jsonSaved detection presets.
settings/experiments/Saved custom experiment designs.
settings/wimm.logWarnings and errors of every session (the previous one is kept as wimm.log.old when the file grows large).
backup/Automatic backup: one Excel file per video and experiment, written after every run (unless another backup folder is set).

A damaged settings file is never overwritten: it is renamed to <name>.bad-<date> and defaults are used.

Reproducibility

  • Every export records the app version (first row of Video Config, e.g. "WIMM 1.0.0") and every setting used. The version is also in the window title.
  • Analyse a whole study with one version. Results of different versions should not be mixed without checking.
  • Keep the backup files and the videos: re-running a video with the same settings and version gives the same numbers.
