Object Location

Spatial memory: two identical objects, one moved to a new place. A mouse that remembers explores the moved object more.

Set-up is the same as Novel Object, except the roles are Stationary and Moved.

  1. Arena; place Object A and B at their positions in this video; size and pad.
  2. Set the roles: which object was moved (stays per video in Run all).
  3. Scale, check the nose marker, run.

Measures

As in Novel Object: time, bouts and latency per object, and

  • discrimination_index = (moved − stationary) ÷ (moved + stationary)
  • preference_pct_moved = moved ÷ (moved + stationary) × 100
Two objects may have the same name; their columns stay apart because they are labelled Object A / Object B.
