01 Video

Adding videos

  1. Click + Add at the top of the Queue and pick one or more files, or drag files from Windows Explorer onto the Queue.
  2. Supported: .mp4 .avi .mov .mkv .wmv .flv. Paths with spaces or non-English letters work.
  3. Click a video in the Queue to show it in the panel. The 🗑 button at the top of the Queue removes all videos; ✕ on a row removes one.
A video that is missing, empty or damaged stays in the Queue with the message "Can't open … — the file is missing, empty or damaged." Remove it or replace the file.

What the card shows

FieldMeaning
FileThe video's file name.
ResolutionWidth × height in pixels.
Frame rateFrames per second. detected = read from the file (when the file reports an impossible value, it is measured from the frames' time stamps).
FPS overrideAuto (0) uses the detected rate. Type a value only when you know the file's rate is wrong. All times and speeds use this rate.
TrimThe part of the video that is analysed (start → end, in seconds). Set it with ✂ on the Queue row — Trim and crop.
If the app says "Can't read this video's frame rate. Set an FPS override", the file reports an impossible rate and has no usable time stamps. It refuses to guess (a wrong rate makes every time and speed wrong). Enter the real rate of your camera in FPS override and run again.

Recording gaps

Some recorders drop frames. The app reads every frame's real time stamp, so a gap keeps its real length: duration and average speed include it, and no false speed spike appears across it. Zone times only count frames where the mouse was seen. See Locomotion measures.
