Multi-Run — find the best settings

Multi-Run tracks the loaded video several times, each time with a different value of one or more settings, and writes all results side by side in one Excel file. Use it to find the right settings for a camera / set-up before analysing a study.

Open it with Multi run… in the Tracking card.

Step by step

  1. Load the video you want to test (click it in the Queue) and set it up completely.
  2. Open Multi run…, pick a Variable (e.g. Sensitivity, Tracking model, Smoothing, FPS override …) and tick its Values.
  3. Pick another variable and tick its values, if you want to vary two at once.
  4. Combine: All combinations runs every pairing; the sweep plan shows the list of runs. Remove / Clear all edit the plan.
  5. Choose the Output folder and click Run sweep.

Every setting you don't vary stays as it is in the panel. The video is tracked once per run, so many combinations take a while. Stop finishes the current run and skips the rest.

The result file

multirun_<video>_<variable>_<date-time>.xlsx holds a Sweep Compare sheet (each measure in one row, one column per variant, with each variant's graphs), one sheet per variant with its results, and a Settings sheet (the varied values and every fixed setting, plus the app version).

Good practice: pick the settings whose results agree best with a human scorer on a few test videos, save them as a detection preset, and use them for the whole study.
