07 Tracking

Model

ModelUse
Median BG (default)Builds the empty arena from frames sampled over the whole video. Validated; handles a mouse that freezes most of the session, light or dark mice and light flicker. Use this for results.
HSV thresholdPlain colour / brightness threshold — a dark mouse on a light floor.
MOG2, KNN, Frame differenceExperimental. In validation MOG2 overestimated distance by ~50 %, KNN misplaced the mouse in about a third of frames, Frame difference missed a slow or still mouse. Not for results.
CNT, GSOC, LSBPNeed the opencv-contrib package; not installed by default.

The ⚙ button shows the model's tuning values. Settings → Extra features → Open models preview shows every model's default values.

Speed and quality

ControlMeaning
Process res.Shrinks frames before detection: Full, 75 %, 50 % (~2× faster), 25 % (~4× faster). Positions are scaled back to full size. Check detection after lowering it — a small mouse may get lost.
Frame skipAnalyse every Nth frame and fill the skipped ones by straight lines. Off = every frame (most accurate).
SmoothingRolling-median filter on the positions after tracking (Off / 3 / 5 / 7 / 9 frames). Removes single-frame jumps; larger values can flatten fast turns.
Nose detectionFinds the nose and tail tip every frame. Needed for object tests (on by default for Novel Object / Object Location); costs 1–3 ms per frame.
Live cell overlay during trackingUpdates the zone overlay every frame while tracking (slower). Off by default — everything is shown after the run anyway.
